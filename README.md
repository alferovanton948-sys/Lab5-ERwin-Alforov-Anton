Варіант №1 — «Зарплата 1»

Мета роботи
Проєктування логічної та фізичної моделей бази даних, нормалізація відношень, визначення первинних і зовнішніх ключів та генерація SQL-скрипту.
Структура бази даних
employees — співробітники.
positions — посади.
tariff_categories — тарифні категорії.
education — освіта.
education_requirements — вимоги до освіти.
payroll — нарахування заробітної плати.
Виконані завдання
Створено логічну модель бази даних.
Створено фізичну модель для MySQL.
Визначено первинні та зовнішні ключі.
Побудовано шість зв'язків між сутностями.
Реалізовано складений первинний ключ.
Виконано декомпозицію відношень.
Згенеровано SQL-скрипт засобами ERwin.
Файли репозиторію

Lab5_Alforov_ZKS21.sql — згенерований SQL-скрипт.
Висновок
У ході роботи розроблено логічну та фізичну моделі бази даних для обліку співробітників і нарахування заробітної плати. Визначено структуру таблиць, ключі та зв'язки між ними.
